# Singlify connectors website (prototype)

Static site built with Astro and TypeScript. Source of truth for content: `src/data/`.

```
npm install
npm run dev          # local dev
npm run build        # static output in dist/
npm test             # Playwright + axe (builds and previews first)
npm run placeholders # refresh the placeholder list below
```

## Where things live

- `src/data/connectors.json`: connectors, routes, choices, AppExchange examples, use-case copy (your handover file, unchanged).
- `src/data/flows.json`: swimlane stages, lanes and attachments. Flows are composed from a stage library, so adding servicing or collections later is a data change.
- `src/data/open-items.json`: every open item from the handover, shown as a visible placeholder where it belongs.
- `src/lib/data.ts`: loads and validates content at build time (partner names, human steps, routes). A bad edit fails the build.
- `src/components/Swimlane/`: `LaneGrid` (wide screens, arrows computed from fixed card geometry in `src/lib/layout.ts`) and `StageList` (phone). Both render from the same resolved flow.
- Placeholder text in the data ("to confirm", "to map", `[...]`) is detected automatically and marked on the page.

## Notes

- Cera Pro and the logo files are not in the repo. The font falls back to Calibri, then system sans-serif; the nav shows plain text.
- No icons: the Futuro set was not available and no substitute was used.
- Output is static, so it can be hosted standalone or embedded in the Webflow site.
